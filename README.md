# Regular Auto Update — ระบบสร้างตารางงานบำรุงรักษาประจำ

ระบบสร้างตารางงานบำรุงรักษาประจำ (Regular Maintenance Schedule) สำหรับพื้นที่ CTA & PTA No.1 Plant, GC-M PTA

## คืออะไร

เป็นเว็บแอปแบบ **single-file** (ไฟล์ HTML ไฟล์เดียว) ทำงานแบบ **local-first** — เก็บข้อมูลในเครื่องผ่าน IndexedDB ใช้งานได้แบบออฟไลน์เต็มรูปแบบหลังโหลดหน้าเว็บครั้งแรก ไม่มี backend/server logic

ไฟล์หลักของโปรเจกต์คือ `Regular_auto_update.html`

## วิธีเปิดใช้งาน

มี 2 แบบ:

1. **เปิดไฟล์โดยตรง** — ดับเบิลคลิก `Regular_auto_update.html` เปิดในเบราว์เซอร์ได้เลย ใช้งานได้ทันที แต่ในโหมดนี้การแก้ไขจะไม่บันทึกอัตโนมัติ (ดูรายละเอียดในคู่มือของแอป)
2. **วางบน Static Server/Intranet** (แนะนำสำหรับใช้งานจริงหลายคน) — เพื่อให้ทุกการแก้ไขบันทึกอัตโนมัติผ่าน IndexedDB

## ฟีเจอร์หลัก

- สร้างตารางทำเครื่องหมาย O รายวันของแต่ละเดือน จากงานตั้งต้นประมาณ 74 รายการ
- เพิ่ม/แก้ไข/ลบงาน พร้อมกำหนดความถี่ได้หลายรูปแบบ (รายวัน, ทุก N วัน, รายสัปดาห์, รายเดือน, ทุก 3/6 เดือน, ตาม DCS ฯลฯ)
- Export Excel, Print/Save-as-PDF, Export/Import JSON (สำรอง-กู้คืนข้อมูล), บันทึกพร้อมข้อมูล (Standalone HTML)
- โหมดมืด/สว่าง (จำค่าอัตโนมัติ)

## Tech Stack

HTML/CSS/JavaScript ล้วน ไม่มี build step — Tailwind CSS (CDN), SheetJS/xlsx (CDN, pinned + SRI), IndexedDB
